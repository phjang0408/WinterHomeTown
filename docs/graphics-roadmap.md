# 겨울 동네 그래픽 개선 로드맵

## 방향
- 분위기: 화창한 파란 하늘에 눈이 내리는 맑은 겨울 낮. 햇빛 받은 눈은 희게, 그늘은 푸르게. (밤 장면으로 바꾸지 않기로 함, 2026-11-12)
- 한국 느낌: 한국 동네에서만 보이는 실루엣과 기호(아파트 베란다, 동 번호, 한글 간판, 전봇대, 겹겹 능선)를 우선한다.
- 기법: 외부 모델 없이 Three.js만 사용. 텍스처 한 장을 붙인 상자 대신 부품을 실제 입체로 세워 그림자가 지게 하고, 부품은 색깔별로 `boxesGeo()`로 합쳐 그리기 횟수를 줄인다.
- 작업 방식: 요소를 하나씩 소품으로 만들고(갤러리에서 확인) → 맵에 배치 → 확인 후 다음 요소.

## 메쉬 기준 (새 방식, 2026-11-12부터)
참고 분석: `claude/mesh-reference-genex-bench.md`. 첫 예시는 `props/parkBench.js`의 공원 벤치.
- 소품은 미터 단위로 만들고 `UNIT`(= 1/0.85)을 곱해 게임 단위로 바꾼다. 원점은 바닥 중심, 정면 +z.
- 형태: 상자 대신 곡선(`curveZY`) → 둥근 단면 쓸기(`sweep`) / 윤곽 둥근 압출(`extrudeProfile`). 모서리는 모두 둥글게.
- 맞물림: 기준 곡선 하나를 정하고 부품 위치는 그 곡선에서 계산한다 (예: 벤치 각재와 받침 레일).
- 재질: `core/texkit.js`의 PBR 재질 묶음(나무·도장 철·눈). 노이즈로 만든 색·노멀·거칠기 텍스처.
- 명암: `bakeAO()`로 정점 색 가짜 AO를 기본으로 넣는다.
- 예산: 소품 하나에 그리기 3~4회, 재질 3개 이하, 삼각형 1만 개 안팎. 반복 부품은 InstancedMesh.
- 도구 위치: `core/meshkit.js`, `core/texkit.js`.
- 추가 도구 (2026-11-12): `loft`(단면 고리 잇기: 차 몸통·휘는 벽), `tube`(굵기 변하는 관: 난간·가지), `lathe`(회전체), `box`(둥근 모서리 상자, uv 미터), `fillet`(꺾인 선 둥글리기), `ridge`·`blob`(눈 이랑·덩어리), `Parts`(재질별 모으기). 재질은 콘크리트·아스팔트·보도블록·금속·광택(유리)·자동차 도장·나무껍질·플라스틱·투명판·바닥 페인트가 늘었다.
- 같은 소품을 여러 곳에 놓을 때는 `W.placeMany(이름, [{x, z, rot, s, color}])`로 인스턴스로 그린다 (주차된 차 수십 대도 차종당 그리기 5회). 소품에 `height(x, z)`를 주면 올라설 수 있다 (정자 마루).
- 소품 조립은 `props/kit.js`의 `assemble()`을 쓴다 (UNIT 배율, 그림자, 삼각형·그리기 횟수 기록).
- 건물은 창·난간·실외기까지 실제 상자로 세우고 색은 정점 색으로 넣어 벽체 전체를 한 번에 그린다 (`props/aptTower.js`). 햇빛 받는 벽은 순백으로 날아가므로 벽 색은 `0xd6d9d9` 정도의 밝은 회색을 쓴다.

## 조명 기준값 (게임과 갤러리 공통, `core/look.js`)
three r160은 색 관리가 켜져 있고 조명 세기가 물리 단위라서 r128 때 값과 다르다. 바꿀 때는 `look.js` 한 곳만 고친다.
- 출력 sRGB, 톤 매핑 없음 (눈밭이 회색으로 죽지 않도록)
- 반구광 `0xbdd9ff / 0xf6f8fa`, 세기 0.46π
- 주변광 `0xe6efff`, 세기 0.06π
- 해 `0xfff5e6`, 세기 1.45π, 방향 `SUN_OFF = (-70, 78, 75)` (남서쪽, 고도 약 37도)
- 환경맵: 파란 하늘 + 눈밭 반사 그라데이션을 PMREM으로 구움. PBR 재질만 받으며 세기 0.35.
- r128 화면과 같은 위치 픽셀을 비교해 밝기를 맞췄다 (양지 눈밭 RGB 차이 ±10 이내).
- 해 외에 방향광을 추가하지 않는다. Lambert 재질에서는 그림자 마스크가 모든 방향광에 곱해져 그늘진 면에 줄무늬가 생긴다.
- 캔버스 텍스처는 `colorSpace = SRGBColorSpace`, 하늘 셰이더 색은 변환 없이 그대로 넘긴다.
